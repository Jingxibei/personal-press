# Personal Press

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

専門分野、情報源、モデルを自分で選ぶ、毎日の個人新聞。生成した号をパソコン内に保存し、内蔵リーダーで読むほか、電子書籍端末向けに書き出したり、紙に印刷したりできます。

**`0.1.0-alpha.1` はソースコードのプレビュー版です。** Windows、macOS、Linux のデスクトップ用ビルド設定は含まれていますが、完成済みインストーラーはまだ公開していません。正式なコード署名と macOS の公証も未完了です。モバイル版、端末への自動配信、ホスト型サービスは[ロードマップ](ROADMAP.md)に記載した計画です。

無料のオープンソースコアは [Apache-2.0](LICENSE) ライセンスです。Personal Press のアカウントや会員契約は不要です。クラウドモデルの API 利用料金は、選択した提供元の規則に従います。

## ソースから起動する

Windows、macOS、または Ubuntu のデスクトップ環境に **Node.js 22 以降と npm** を用意してください。ソースをダウンロードして展開するか、このリポジトリをクローンし、プロジェクトのディレクトリで実行します。

```sh
npm ci
npm start
```

初回の `npm ci` にはインターネット接続が必要です。依存パッケージと Electron を取得し、固定されたフォントパッケージから欧文・中国語・日本語のフォントをローカルに準備します。インストール後、見本紙や既刊号を読むためにフォント CDN へ接続することはありません。Python や Docker は不要です。

最初は**オフライン見本紙**を開いてください。見本は明示されたオリジナル例文であり、実際の最新ニュースではありません。モデルを呼び出さず、正式な日刊号にも数えません。新規インストールでは、自動発行と自動印刷はどちらも無効です。

`npm run preview` では、表示されたローカルアドレスから閲覧画面だけを試せます。ブラウザープレビューの設定はページのセッション内のみで、実際の生成、キーの保存、書き出し、プリンター操作はできません。デスクトップ機能には `npm start` を使います。

## 現在の実装

| 分野 | プレビュー版の動作 |
| --- | --- |
| モデル | 自分の OpenAI、Gemini、Grok、DeepSeek API キーを使用。ループバック上の OpenAI 互換ローカルモデルにも接続可能です。 |
| 専門分野 | 14 の大分野から専門領域、テーマへ絞り込み。複数の方向、自由記述、読む視点、5 段階の深さを設定できます。 |
| 言語 | 中国語・英語・日本語の画面。新しい号はこの中から任意の 2 言語を選び、おおよその比率を指定できます。 |
| 閲覧 | 内蔵リーダー、日付の新しい順の履歴、新聞/集中表示、文字サイズ、4 種類の落ち着いた紙面色。 |
| 書き出し | 同じ保存済みの号から PDF、EPUB、HTML を作成。記事を再生成しません。EPUB は簡素なリフロー形式です。 |
| 毎日の発行 | 固定 IANA タイムゾーン、最大 20 分前の準備、一日一号の確定原稿、起動が遅れた場合は当日分だけを作成。 |
| 印刷 | OS のプリンター一覧、明示的なテストページ、システムダイアログによる手動印刷、テスト後に有効化できる自動印刷。 |
| ローカル欄 | 日付から生成し唯一解を確認する数独、小さな英単語パズル集、なぞなぞ、ジョーク、手入力の予定表。 |

問題集は小規模で、繰り返し掲載されます。英単語パズルの中国語・日本語はヒントの翻訳であり、本格的な中国語・日本語クロスワードではありません。商業漫画は含まれません。この alpha では、一部の内部エラーや点検メモが英語で表示される場合があります。

## 最初の正式版を作る

1. 設定で表示言語、新聞名、発行タイムゾーンを指定します。
2. 大分野だけを選ぶか、専門領域やテーマまで絞り込みます。自由記述だけでも追加でき、複数の方向と個別の深さを保存できます。
3. **公開 HTTPS RSS／Atom フィード**を少なくとも一つ追加し、有効にします。初期状態の出典は空です。この版はフィードを自動で検索・発見しません。
4. モデル提供元を選び、自分の API キーを保存します。モデル一覧を取得するか、利用可能で対応するテキストモデルの ID を入力します。
5. 2 言語、目安の比率、最大記事数を設定します。既定は最大 6 記事で、1〜12 の範囲です。根拠が少なければ記事数は減ります。
6. 設定を保存して「今日の正式版を生成」を選びます。自動発行を無効にしていても、手動生成は当日の正式な号を使用します。
7. 出典、資料の締切、不確実性、点検メモを読んでから、必要に応じて保存済みの号を書き出し・印刷します。
8. 毎日の自動発行が必要なら、希望時刻を設定して明示的に有効にします。自動印刷は別途プリンターを選び、テストしてから設定します。

アカウントのモデル一覧に表示されても、すべてのモデルが現在のテキスト API と適合するとは限りません。要求が失敗しても、別の提供元や有料モデルへ自動的に切り替えません。

### 分野と深さ

14 の大分野は、情報技術・デジタル製品、産業・ロボット・製造、医療・生命科学、金融・ビジネスサービス、法律・政策・公共分野、エネルギー・資源・環境、建築・土木・都市、交通・物流・航空宇宙、地理空間・地球科学、農業・食品・生物資源、消費・小売・サービス、教育・社会科学・人文、メディア・文化・デザイン、数学・物理・基礎科学です。[分野カタログ](src/shared/domains.mjs)で実際の選択肢を確認できます。

読む方向は「何を追うか」、視点は研究、技術実践、経営・運用、製品・ユーザー、政策など「どの角度から読むか」を指定します。分類に合わない仕事には自由記述を使えます。設定は選題と説明を導きますが、すべての分野について毎日十分な新着資料があるとは限りません。

| 深さ | 求める内容 |
| --- | --- |
| 1 · 速読 | 何が変わったか、必要な用語、短い背景説明。 |
| 2 · 業界概観 | 実務や作業の流れとの関連、主な根拠の限界。 |
| 3 · 専門読書 | 仕組み、前提、条件付きの実務上の影響。既定値です。 |
| 4 · 詳細分析 | 資料が支持する範囲で、方法、適用条件、制約、別の解釈を検討。 |
| 5 · 専門家向け | 根拠、想定される状況、判断の境界をさらに検討し、不足資料を明示。 |

深さを上げても点検基準は下がりません。短いフィード要約が、設定だけで十分な根拠を持つ調査報告に変わることはありません。

### 2 言語の割合と確定した号

比率は**本文段落の配分の目安**であり、単語数、文字数、紙面面積の厳密な比率ではありません。両言語に見出しと要約を残し、割合の大きい言語には通常、より詳しい説明を割り当てます。文字体系や資料の量によって実際の比率は変わります。

既刊号の文字サイズ、配色、表示形式、言語比率を変える操作は、保存済みの内容を端末内で組み直すだけです。モデルを呼ばず、短い要約から未保存の長文を作ったり、別の言語を追加したりしません。新しい言語の組み合わせ、出典、専門分野は今後生成する号に適用されます。

正式版の内容は、前日からの早期準備も含め、**準備が完了した時点で確定**します。手動と定時の生成は同じ日付を共有し、書き出しや再配置で号が増えることはありません。見本紙は常に別扱いです。

## 「点検済み」の意味

この版が読むのは**フィードの見出し、日付、長さを制限した要約**です。記事全文の閲覧、課金制限の回避、独立した取材は行いません。各フィードの新しさの期間は既定で **48 時間**、設定範囲は 1〜168 時間です。日付不明、締切より未来、期間外、安全でないリンク、空の要約などは除外します。

出力構造、使用可能な出典 ID、根拠の引用が実際の要約に含まれるか、単純な重複を検査します。既定では、**同じ選択済みモデルにもう一度要求を送り**、素材との整合性を点検させます。裏付けがない、または素材と矛盾すると判断された記事は除外します。追加のモデル点検を無効にしても、構造と引用の機械的な検査は続きます。

これらは事実の正しさを保証しません。引用の一致だけで、すべての推論が支持されるとは限りません。モデルの再度の同意は独立した事実確認ではなく、複数サイトが同じ一次報道を転載していることもあります。現在の重複処理は正規化 URL、見出し、単純な記事の反復が中心です。出来事単位の包括的な整理や一次報道の追跡は今後の課題です。

使える資料や点検を通った記事がなければ、正式版を保存せずエラーで停止します。代わりの新聞を捏造しません。仕事の判断に足りる資料かどうかは、原資料と明示された限界を確認してください。[アーキテクチャ](docs/architecture.md)に処理の詳細があります。

## API アカウント、料金、地域

本アプリは提供元の **API キー**を使い、チャット製品の Cookie や会員セッションを API 認証の代わりにしません。API の利用枠、課金、プラン特典は開発者アカウントの現行規則に従います。チャット会員の契約だけで本アプリの API 使用が賄われるとは考えないでください。例えば OpenAI は [ChatGPT と API の別課金](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)を説明しています。

| 提供元 | 現在のアダプター | 公式資料 |
| --- | --- | --- |
| OpenAI | Responses API | [OpenAI API](https://developers.openai.com/api/docs/) |
| Gemini | `generateContent` | [Gemini API](https://ai.google.dev/gemini-api/docs) · [課金](https://ai.google.dev/gemini-api/docs/billing) |
| Grok | Chat Completions API | [xAI 開発者文書](https://docs.x.ai/developers) · [API 料金](https://docs.x.ai/developers/pricing) |
| DeepSeek | Chat Completions API | [DeepSeek API 文書](https://api-docs.deepseek.com/) |
| ローカル | ループバック上の OpenAI 互換チャット API | 例：`http://127.0.0.1:11434/v1`。対応サーバー、モデル、必要な計算資源を自分で用意します。 |

通常、一号には生成要求が一回、追加点検が有効ならさらに一回の要求が必要です。定時生成の失敗後は最低 10 分待って再試行し、当日三回の失敗で自動試行を停止します。手動の再試行では追加料金が発生する場合があります。**一日一号は API 料金の上限ではありません。** 提供元の使用量設定も確認してください。

米国、カナダ、中国本土、日本を含め、すべての地域で全提供元・モデル・フィードが利用できる保証はありません。アカウント資格、通信、モデル公開範囲、支払い方法は外部サービスに依存します。ローカルモデルならクラウド推論を避けられますが、新しいフィードの取得には接続が必要です。

## 定時発行、印刷、電子書籍端末

**パソコンがスリープせず、アプリが動作している必要があります。** クラウド調整、端末の自動起動・復帰、ログイン時の起動タスクはありません。00:05 発行なら前日の 23:45 から準備でき、起動が遅れた場合は当日分だけを作ります。過去の日の号をまとめて後追い発行しません。夏時間とタイムゾーン変更は日付処理と保存済みのガードで扱います。

自動印刷は初期状態で無効です。OS に登録されたプリンター、用紙、両面設定を明示的に選び、テストページを送って実物を確認してから有効にしてください。自動印刷は一部、白地に濃い文字で、**1〜12 ページ**の設定上限を持ちます。キュー受付の成功は「送信済み」であり「印刷完了」ではありません。結果が不明な場合、自動で再送しません。手動印刷はシステムダイアログを開きます。[印刷ガイド](docs/printing.md)も確認してください。

PDF、EPUB、HTML を書き出し、電子書籍端末が既に備える文書取り込み方法を使えます。PDF はページ構造を保ちやすく、EPUB は小さな画面でのリフローに適します。現行版は Kindle、iReader/掌阅、BOOX、reMarkable、Kobo へのアプリ導入、ペアリング、自動配信を行いません。対応形式と転送手順は端末・ソフトウェアの版に依存し、書き出し機能だけで全端末の互換性を保証するものではありません。

## プライバシーと保存

設定、新聞、予定、処理履歴はローカル JSON に保存します。**アーカイブ全体をアプリが暗号化しているわけではありません。** API キーは通常設定から分離し、利用可能な Electron の OS 保護機能を使います。安全な永続保存が使えない場合、Linux `basic_text` を含め、キーはそのアプリセッションのメモリだけに保持します。

クラウドモデルを選ぶと、出典の要約と専門分野の設定が提供元へ送られます。予定はアプリ内で手入力し、すべてのモデル呼び出し後にローカルで追加します。プロンプトには含めず、OS のカレンダーも読みません。ただし、書き出し・印刷した新聞に予定が含まれることはあります。

この alpha にアカウント用サーバー、分析データのアップロード、クラウド同期はありません。保存・バックアップ・データの境界は[プライバシー](docs/privacy.md)、問題の報告は[セキュリティ](SECURITY.md)を参照してください。

## 開発と各 OS でのビルド

```sh
npm test
npm run check
npm run dist
```

`npm run dist` は対象の OS 上で実行します。設定された対象は Windows x64 NSIS、macOS arm64/x64 DMG、Linux AppImage/deb で、出力先は `dist/` です。追加のダウンロードや OS の依存関係が必要な場合があります。この設定は、署名済みインストーラーや全ハードウェアでの検証を公開済みという意味ではありません。

`npm run pack` は展開形式のアプリを、`npm run source:zip` はソース ZIP と SHA-256 ファイルを作ります。[コントリビューション](CONTRIBUTING.md)に開発方針があります。依存パッケージとフォントのライセンスは[第三者の権利表示](THIRD_PARTY_NOTICES.md)に従います。ソフトウェアのライセンスは第三者のニュースを再配布する権利を付与しません。

無料コアですでに、複数の専門分野と自分で選んだ出典を使えます。有料の出典発見・分野横断整理、ホスト型の一括サービス、端末自動配信、iOS/Android/HarmonyOS の独立したモバイル管理、許諾済み漫画は[計画段階](ROADMAP.md)です。
