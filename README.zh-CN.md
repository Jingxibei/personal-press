# Personal Press · 个人日报

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

一份由你选择专业方向、新闻来源和模型的每日报纸。在电脑中保存与阅读，也能将同一期导出到电子书阅读器，或打印成纸报。

**`0.1.0-alpha.1` 是源码预览版。** 项目已包含 Windows、macOS 和 Linux 的桌面打包配置；现成安装包尚未发布，正式代码签名和 macOS 公证尚未完成。移动端、设备自动推送和全托管服务仍在[路线图](ROADMAP.md)中。

免费开源核心采用 [Apache-2.0](LICENSE) 许可，无需注册 Personal Press 账户或购买本项目会员。使用云模型产生的 API 用量由所选服务商计费。

## 启动源码预览版

在 Windows、macOS 或 Ubuntu 桌面环境安装 **Node.js 22 或更新版本及 npm**。下载并解压源码，或克隆本仓库，进入项目目录后运行：

```sh
npm ci
npm start
```

首次 `npm ci` 需要联网，会下载依赖和 Electron，并将依赖包中的拉丁文、中文、日文字体准备到本地。安装完成后，读样报和已有日报不会向字体 CDN 请求资源。不需要 Python 或 Docker。

第一次可以先打开**离线样报**。样报是明确标记的原创示例，不代表真实最新新闻，不调用模型，也不占正式刊期。全新安装的每日自动出刊和自动打印都默认关闭。

`npm run preview` 可启动仅供阅读界面演示的本地浏览器预览，地址会显示在终端。浏览器预览只在本次页面会话保留设置，不能真实生成、保存密钥、导出或访问打印机；完整桌面功能请使用 `npm start`。

## 当前已实现

| 功能 | 源码预览版的实际行为 |
| --- | --- |
| 模型 | 自备 OpenAI、Gemini、Grok 或 DeepSeek API 密钥；也可连接本机回环地址上的 OpenAI 兼容模型服务。 |
| 专业方向 | 14 个一级领域，逐级细化到二级方向和专题；支持多个方向、自由叙述、阅读视角及五档深度。 |
| 语言 | 中文、英文、日文界面；新一期内容可从三种语言中任选两种，调整近似篇幅比例。 |
| 阅读 | 内置阅读器、按日期倒序排列的历史、报纸/专注版式、字号和四种纸面配色。 |
| 导出 | 从同一期已保存内容生成 PDF、EPUB 和 HTML，无需再次生成文章。EPUB 使用便于电子书重排的简化版式。 |
| 每日出刊 | 固定 IANA 时区、最多提前 20 分钟准备、每个日期最多一期正式日报；晚启动只补当天。 |
| 打印 | 读取操作系统打印机名单、主动测试页、系统对话框手动打印，以及测试后可选的每日自动打印。 |
| 本地副刊 | 按日期生成并检查唯一解的数独、小型原创英语填字、谜语、笑话，以及手动录入的本地行事历。 |

副刊题库规模较小，会循环使用。填字是英语迷你文字游戏，中日文提供提示译文，并非完整的中文或日文填字。当前没有商业漫画。部分底层错误和检查备注在此 alpha 中仍可能显示英文。

## 制作第一期正式日报

1. 在设置中选择界面语言、报纸名称和固定出刊时区。
2. 选择一级领域；需要时继续细化到方向和专题，也可以完全用自己的话描述。可以添加多个阅读方向，并分别覆盖默认深度。
3. 添加并启用至少一个**公开 HTTPS RSS／Atom 地址**。来源默认空白；本版还不会替你搜索和发现新闻源。
4. 选择模型服务，保存自备 API 密钥，再读取模型列表或填写账户可用且适配文本接口的模型 ID。
5. 选择两种阅读语言、目标篇幅比例和每期最多文章数。默认最多 6 篇，可设置 1–12 篇；证据不足时实际篇数会减少。
6. 保存设置，点击“生成今日正式日报”。即使没有开启自动出刊，手动生成也会使用今天的正式刊期。
7. 阅读来源、素材截止时间、证据限制和检查备注，再按需要导出或打印这份存档。
8. 如需每天自动出刊，再明确开启出刊计划。自动打印需要单独选择打印机并完成测试。

模型列表来自你的服务商账户，不能保证列表中的每一个模型都适用于当前文本接口。请求失败时，应用不会自动切换到其他服务商或其他付费模型。

### 方向与深度怎样选择

14 个领域包括：信息技术与数字产品；工业、机器人与制造；医疗健康与生命科学；金融与商业服务；法律、政策与公共事务；能源、资源与环境；建筑、土木与城市；交通、物流与航空航天；地理空间与地球科学；农业、食品与生物资源；消费、零售与服务；教育、社会科学与人文；传媒、文化与设计；数学、物理与基础科学。完整选项见[领域目录](src/shared/domains.mjs)。

“方向”决定关注什么，“视角”决定从工程实践、管理运营、产品用户、研究或政策等角度怎样阅读。特殊领域保留自由描述。设置会指导选题和解释，但不保证每天每个方向都有足够的新材料。

| 深度 | 希望得到的内容 |
| --- | --- |
| 1 · 速览 | 发生了什么、必要术语和简短背景。 |
| 2 · 行业简报 | 与工作流程、实际应用的联系，以及主要证据限制。 |
| 3 · 专业阅读 | 机制、假设和有条件的专业影响；这是默认档。 |
| 4 · 深入分析 | 在材料允许时讨论方法、适用条件、局限和替代解释。 |
| 5 · 专家视角 | 更细致地审视证据、情景和决策边界，明确缺失的信息。 |

深度增加不会降低核验要求，也不会让一段来源摘要变成已有充分依据的深度研究。材料薄弱时，应减少内容或明确说明不足。

### 双语比例与已定稿的刊期

比例滑块对应**近似的正文段落预算**，不是精确的字数、字符数或纸面面积。两种语言都会保留标题和概要；占比较高的一侧通常获得更完整的解释。语言文字系统与素材质量都会影响实际篇幅。

读取存档时，调整字号、配色、版式和语言占比只在本机重排已经保存的内容，不会调用模型。它不会把原来只有概要的一侧补成长文，也不会给旧报增加第三种语言。新语言组合、来源和专业偏好用于之后新生成的刊期。

正式日报从**准备完成时**就固定内容，包括提前准备好的下一日刊期。手动生成与定时生成共用同一日期；下载、导出和改版式不会增加刊期。离线样报始终独立。

## “已检查”不等于事实保证

当前读取的是**订阅源标题、日期和有限长度的摘要**，不会获取原文全文、绕过付费墙或进行独立采访。每个来源的素材窗口默认 **48 小时**，可配置为 1–168 小时。没有可用日期、晚于截止时间、过旧、链接不安全或缺少摘要的条目会被排除。

系统检查模型输出结构、允许的来源 ID、支持性引文是否确实出现在给定摘要中，以及简单重复。默认还会让**同一个选定模型进行额外一次一致性审读**，排除被判断为无依据或与素材矛盾的文章。关闭额外审读后，确定性的结构与引用检查仍然执行。

这些检查无法保证报道真实，也不能证明每个推论都被引用充分支持。模型第二次赞同第一次输出不构成独立核实，多家网站也可能只是在转载同一条原始消息。本版会过滤规范化 URL、标题和简单稿件重复；跨来源的完整事件聚类、原始报道追溯及独立性判断仍待完善。

如果没有可用素材，或没有文章通过检查，应用会报错并停止，不会编造一份替代日报。请依据原始来源和文中限制判断资料是否足以支持你的工作。实现细节见[架构说明](docs/architecture.md)。

## API 账户、费用与地区

本项目使用服务商的 **API 密钥**，不会读取聊天产品的登录 Cookie，也不使用聊天会员会话代替 API 授权。API 额度、计费及可能的套餐权益按服务商开发者账户的现行规则处理，不应直接假定聊天会员包含本应用所需的 API 用量。例如 OpenAI 明确说明 [ChatGPT 与 API 分开计费](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)。

| 服务 | 当前适配接口 | 官方资料 |
| --- | --- | --- |
| OpenAI | Responses API | [OpenAI API 文档](https://developers.openai.com/api/docs/) |
| Gemini | `generateContent` | [Gemini API](https://ai.google.dev/gemini-api/docs) · [计费](https://ai.google.dev/gemini-api/docs/billing) |
| Grok | Chat Completions API | [xAI 开发文档](https://docs.x.ai/developers) · [API 价格](https://docs.x.ai/developers/pricing) |
| DeepSeek | Chat Completions API | [DeepSeek API 文档](https://api-docs.deepseek.com/) |
| 本地模型 | 本机 OpenAI 兼容聊天接口 | 自行运行适配的服务和模型，例如 `http://127.0.0.1:11434/v1`，并准备足够的本地算力。 |

成功生成一期通常需要一次生成请求，开启额外模型审读时还会增加一次请求。定时生成失败后至少间隔 10 分钟重试，当天累计三次失败后停止自动尝试；主动手动尝试可能继续产生费用。**每天最多一期不等于 API 消费封顶**，请同时查看服务商账户的用量控制。

本项目不能保证所有服务商、模型和来源在美国、加拿大、中国大陆、日本或其他地区都可用。账户资格、网络连通、模型开放范围和付费方式由外部服务决定。使用本地模型可避免云端推理请求，但获取新订阅源内容仍需联网。

## 定时、打印与电子书阅读器

**电脑必须保持唤醒，应用必须运行。** 本版没有云端调度、自动唤醒服务或登录启动任务。00:05 的目标出刊可以在前一天 23:45 开始准备；晚开机只补当天，不补发过去几天的旧刊。夏令时和跨时区修改通过日历日期与持久化保护处理。

自动打印默认关闭。请先明确选择操作系统中已安装的打印机、纸型和双面方式，主动打印并检查测试页，再启用自动打印。自动任务只提交一份，使用白纸深色文字，并受 **1–12 页**可配置上限约束。系统队列返回成功只记为“已提交”，不宣称“已实际印出”；结果不确定时不会自动重打。手动打印会打开系统对话框。详见[打印说明](docs/printing.md)。

同一期可导出 PDF、EPUB 和 HTML，再使用阅读器已有的文件导入方式。PDF 适合保留页面结构，EPUB 更便于小屏重排。本版还不会在 Kindle、掌阅、BOOX、reMarkable、Kobo 上安装应用、配对或自动推送。具体支持的文件格式和传输流程取决于设备及其软件版本，导出格式不代表所有设备都能无差别接收。

## 隐私与本地保存

设置、日报、行事历和任务历史保存在本机 JSON 中，**整个档案没有由本应用加密**。API 密钥单独交给 Electron 可用的系统安全存储；安全持久化不可用时，包括 Linux `basic_text` 情况，密钥仅留在应用本次会话内存中。

使用云模型时，选定的源摘要和专业偏好会发送给所选服务商。行事历由你在应用内手动输入，模型调用全部结束后才在本地拼入，不放入提示词，也不会读取系统日历。导出或打印的整报可能包含这些日程。

此 alpha 没有内置账户后台、分析数据上传或云同步。备份、凭据迁移及数据边界详见[隐私说明](docs/privacy.md)，漏洞报告见[安全说明](SECURITY.md)。

## 开发与本机构建

```sh
npm test
npm run check
npm run dist
```

请在目标操作系统上执行 `npm run dist`。配置中的目标是 Windows x64 NSIS、macOS arm64/x64 DMG，以及 Linux AppImage/deb，输出在 `dist/`。构建工具可能需要额外下载和系统依赖；有这些配置不代表三个平台的签名安装包或完整硬件验证已经发布。

`npm run pack` 生成未打包的应用目录；`npm run source:zip` 生成源码压缩包和 SHA-256 文件。[贡献指南](CONTRIBUTING.md)说明了开发约定。[第三方声明](THIRD_PARTY_NOTICES.md)列出依赖与字体许可；本项目的软件许可不授予第三方新闻的再发布权。

免费核心已支持自选多个专业方向与来源。付费自动找源、跨行业资料整理、一站式托管、设备自动推送、iOS/Android/HarmonyOS 移动管理以及授权漫画均属[规划项目](ROADMAP.md)，并非此版本已经开放的服务。
